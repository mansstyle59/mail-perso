# AffiAds Mail

Portail de messagerie en français, responsive et installable sur iPhone, hébergé sur GitHub Pages.

## Fonctionnalités
- Accès rapide à la boîte Proton Mail.
- Raccourcis pour la réception, la rédaction et les paramètres du compte.
- Aucun mot de passe, jeton ou contenu de message stocké dans cette application.
- Aucune IA.

## Limite importante
Cette version est un portail : les messages sont lus et envoyés sur le site officiel de Proton. Le compte Proton Mail gratuit ne propose pas l'intégration IMAP/SMTP via Proton Mail Bridge (réservée aux offres payantes éligibles). Ne saisis jamais ton mot de passe Proton dans AffiAds Mail.

## Utilisation
Ouvre le site publié et touche **Ouvrir ma boîte Proton**. Connecte-toi uniquement sur le domaine officiel `mail.proton.me`.

## Déploiement
Dans **Settings → Pages**, sélectionne **GitHub Actions** comme source et vérifie le workflow `.github/workflows/pages.yml`.

## Installation sur iPhone
Ouvre le site publié dans Safari, touche **Partager**, puis **Sur l'écran d'accueil** et **Ajouter**.
