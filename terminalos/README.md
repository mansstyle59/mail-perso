# TerminalOS

Maquette mobile fictive inspirée des contrôles de fenêtre macOS.

## État actuel
- Écran noir plein écran
- Trois boutons rouge, jaune et vert en haut à gauche
- Adaptation aux zones de sécurité des écrans mobiles
- Interactions uniquement simulées ; aucune commande système n'est exécutée

Ouvrir `index.html` dans un navigateur pour prévisualiser la maquette.
